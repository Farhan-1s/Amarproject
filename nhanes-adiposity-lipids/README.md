# NHANES 2021–2023: Central Adiposity vs. Non-HDL Cholesterol

This repository contains the code, figures, and reports for a multi-phase biostatistical analysis using the continuous NHANES 2021–2023 dataset. The project explores the discordant relationship between general body mass (BMI), central adiposity (Waist-to-Height Ratio), and atherogenic lipid profiles (Non-HDL Cholesterol) in US adults.

## Project Structure

* `PROJECT_CARD.md`: Core definitions, variables, hypotheses, and limitations.
* `data/`: Contains the raw CDC `.XPT` files and download instructions (files ignored by Git).
* `src/`: Python scripts for data engineering, auditing, and descriptive statistics.
* `figures/`: Output visualizations generated by the pipeline.
* `reports/`: Written LaTeX reports documenting the findings phase by phase.

## Reproducing Phase 1
1. Install dependencies: `pip install -r requirements.txt`
2. Download the required data by following the instructions in `data/README.md`.
3. Run the analysis pipeline: `python src/phase1_pipeline.py`.
4. Compile the report located at `reports/phase1/main.tex` using any standard LaTeX engine.
